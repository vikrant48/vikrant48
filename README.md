# 🚀 Featured Projects:

### 🩺 [CareSync – Healthcare Management System](https://github.com/vikrant48/CareSync)
AI-powered clinical assistant built with **Spring Boot** & **Angular**, using **Gemini AI** to automate medical history summarization and diagnosis suggestions. Features a HIPAA-compliant security layer with **AES-256 encryption**, **JWT RBAC**, real-time **WebSocket** notifications, and **Redis**-cached APIs delivering sub-100ms response times.

`Spring Boot` `Angular` `Gemini AI` `WebSocket` `Redis` `Supabase`

---

### 🤖 [CogniDocs – Agentic Document Intelligence](https://github.com/vikrant48/pdf-rag-pipeline)
Multi-agent document Q&A platform using **LangGraph**, where specialized agents (Extractor, Analyser, Q&A) collaboratively process contracts and reports. Production-grade **RAG pipeline** with hybrid search (dense vector + BM25) and **Cohere reranking**, plus real-time streaming Q&A via **WebSockets**.

`Python` `LangChain` `LangGraph` `ChromaDB` `FastAPI` `WebSocket`

---

### 🎥 [VIDEOMELA – Video Sharing Platform](https://github.com/vikrant48/Video_Mela_frontend)
Full-stack video streaming platform supporting **1000+ daily active users**, built with **React.js** and **Node.js/Express**. Features secure **JWT + Bcrypt** authentication, **Cloudinary**-powered media management, and **Redux Toolkit** for efficient global state management.

`React.js` `Node.js` `Express.js` `MongoDB` `Cloudinary`
